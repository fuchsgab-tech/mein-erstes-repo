(a) anchorMain[w] = the single job with value 1 in w's snapshot that is still switched on. None if there are 0 or 2+ such jobs.

(b) Step 2 cost (~line 906): −(score + (must ? 1000 : 0) + (calm && j.id === anchorMain[w] ? STICK : 0)), with STICK = 1.2 score points (about one skill level). This is far below the must bonus, so coverage still wins.

- Without a snapshot, append instead: ' Rechnerisch {p}. Neue Dorfbewohner stehen auf 5 – der kleine Unterschied lohnt das Umstellen nicht.'
