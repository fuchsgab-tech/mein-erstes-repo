# Bellwright Arbeitsplan

Web-App für die Job-Prioritäten in Bellwright (Xbox / PC). Läuft als Claude-Artifact:
https://claude.ai/artifact/CegoBeXjbEYmiPDLUqHM1R

## Dateien

- `arbeitsplan.html` – letzter geprüfter Stand der App (alle Tests grün).
- `versionen/v7-veroeffentlicht.html` – die zuletzt veröffentlichte Version.
- `versionen/in-arbeit.html` – Zwischenstand, an dem gerade gebaut wird (kann unfertig sein).
- `planung/` – Roadmap mit allen geplanten Verbesserungen, Notizen und Prüfberichte.
- `tests/` – automatische Tests (Playwright/Node), z. B. `node mk.js ../arbeitsplan.html && node logic.js`.

Inoffizielles Fan-Tool, nicht von Donkey Crew.
